# Energy Mapping Challenge

An interactive map prototype for the [Energy Mapping Challenge](https://energymap.sustaineducation.org), a Sustain/Ed outreach project (in partnership with the University of Cambridge) where primary schools log their solar and wind energy readings.

Built with Leaflet and CARTO Positron tiles. Pins mark participating schools; clicking one opens a panel with live solar/wind readings, kid-friendly comparisons, and a 7-day trend — designed for ages 8–12.

**Status:** Prototype, in review with project coordinator Beth. Target completion end of November 2026.
