# Energy Mapping Challenge

An interactive map prototype for a webmap redesign of the [Energy Mapping Challenge](https://energymap.sustaineducation.org), Sustain/Ed outreach project funded by the University of Cambridge where primary schools log their solar and wind energy readings.

Built with Leaflet and CARTO Positron tiles. Pins mark each participating school. Clicking one opens a panel with live solar and wind readings, kid-friendly comparisons, and a 7-day trend. Designed for ages 7–11.

Status: Prototype, in review with project coordinator Beth. Target completion end of November 2026.
